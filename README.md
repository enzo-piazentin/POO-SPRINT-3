# POO Sprint 3 - Oracle JDBC + Menu interativo

Projeto Java de persistência em Oracle usando JDBC, com CRUD de equipes, trechos, intervenções e geração de relatório de prioridade.

## Visão geral

O sistema permite:
- cadastrar equipes de manutenção;
- listar equipes;
- cadastrar trechos da rodovia;
- listar trechos;
- cadastrar intervenções operacionais;
- listar intervenções;
- gerar e salvar relatório de prioridade no banco;
- validar entradas do usuário antes de persistir os dados.

## Estrutura principal

- `src/Main/Main.java` — menu inicial do sistema
- `src/dao/*DAO.java` — acesso ao banco de dados
- `src/model/*` — modelos/records do domínio
- `src/service/GeradorRelatorio.java` — geração do relatório
- `src/database/ConexaoBanco.java` — conexão com o Oracle
- `src/exception/*` — exceções customizadas

## Pré-requisitos

- Java 17+
- IntelliJ IDEA ou outra IDE Java
- Oracle Database com acesso ao schema da disciplina
- Driver JDBC Oracle (`lib/ojdbc17.jar`)
- Acesso ao banco com usuário e senha válidos

## Configuração do banco Oracle

Abra o DBeaver ou SQL Developer e conecte com o mesmo usuário configurado em `ConexaoBanco.java`.

### 1. Verifique o usuário atual

```sql
SELECT USER FROM DUAL;
```

O retorno deve ser igual ao usuário informado em `ConexaoBanco.java`.

### 2. Verifique se a tabela de equipe possui a coluna DIRECAO

```sql
SELECT COLUMN_NAME
FROM USER_TAB_COLUMNS
WHERE TABLE_NAME = 'EQUIPE_MANUTENCAO'
ORDER BY COLUMN_ID;
```

Se a coluna `DIRECAO` não existir, rode:

```sql
ALTER TABLE EQUIPE_MANUTENCAO
ADD DIRECAO VARCHAR2(10) DEFAULT 'NORTE' NOT NULL;
```

### 3. Verifique as tabelas do projeto

```sql
SELECT TABLE_NAME
FROM USER_TABLES
WHERE TABLE_NAME IN (
    'EQUIPE_MANUTENCAO',
    'TRECHO_RODOVIA',
    'INTERVENCAO_OPERACIONAL',
    'RELATORIO_PRIORIDADE'
)
ORDER BY TABLE_NAME;
```

Se alguma tabela não existir, execute o script de criação do projeto ou recrie os objetos manualmente no mesmo schema.

## Criação das tabelas

Se necessário, a estrutura mínima do banco é:

```sql
CREATE TABLE EQUIPE_MANUTENCAO (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    NOME VARCHAR2(100) NOT NULL,
    ESPECIALIDADE VARCHAR2(100) NOT NULL,
    DIRECAO VARCHAR2(10) DEFAULT 'NORTE' NOT NULL
);

CREATE TABLE TRECHO_RODOVIA (
    KM NUMBER(10) PRIMARY KEY,
    ALTURA_VEGETACAO NUMBER(8,2) NOT NULL,
    TIPO_TERRENO VARCHAR2(30) NOT NULL,
    EQUIPE_ID NUMBER,
    CONSTRAINT FK_TRECHO_EQUIPE
        FOREIGN KEY (EQUIPE_ID)
        REFERENCES EQUIPE_MANUTENCAO(ID)
);

CREATE TABLE INTERVENCAO_OPERACIONAL (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    KM_TRECHO NUMBER(10) NOT NULL,
    TIPO VARCHAR2(60) NOT NULL,
    RESPONSAVEL VARCHAR2(100) NOT NULL,
    DATA_INTERVENCAO DATE DEFAULT SYSDATE NOT NULL,
    CONSTRAINT FK_INTERVENCAO_TRECHO
        FOREIGN KEY (KM_TRECHO)
        REFERENCES TRECHO_RODOVIA(KM)
);

CREATE TABLE RELATORIO_PRIORIDADE (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    URGENTES NUMBER NOT NULL,
    CRITICOS NUMBER NOT NULL,
    ATENCAO NUMBER NOT NULL,
    NORMAIS NUMBER NOT NULL,
    RESUMO CLOB,
    GERADO_EM TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL
);
```

## Como rodar no IntelliJ IDEA

1. Abra o projeto no IntelliJ.
2. Certifique-se de que a pasta `src` está marcada como source root.
3. Confirme que o arquivo `lib/ojdbc17.jar` existe.
4. Vá em `Run > Edit Configurations`.
5. Crie uma configuração para `Main`.
6. Execute a classe `Main.Main`.

A aplicação abre um menu interativo no console.

## Validações implementadas

O menu valida:
- nome obrigatório;
- especialidade obrigatória;
- direção permitida: `NORTE`, `SUL`, `LESTE`, `OESTE`;
- KM não negativo;
- altura da vegetação não negativa;
- tipo de terreno `UMIDO` ou `SECO`;
- responsável obrigatório;
- tipo de intervenção obrigatório.

## Problemas comuns e correções

### 1. ORA-00904: identificador inválido

Sinal de que a tabela ainda não possui a coluna `DIRECAO`.

Executar:

```sql
ALTER TABLE EQUIPE_MANUTENCAO ADD DIRECAO VARCHAR2(10) DEFAULT 'NORTE' NOT NULL;
```

### 2. ORA-00001: restrição exclusiva violada

Sinal de que o valor da chave primária já existe, geralmente por duplicação de `KM` em `TRECHO_RODOVIA`.

Verifique:

```sql
SELECT * FROM TRECHO_RODOVIA ORDER BY KM;
```

Se necessário, use outro KM ou delete o trecho duplicado.

### 3. BigDecimal cannot be cast to Integer

Esse erro foi corrigido no `TrechoRodoviaDAO`, que agora converte corretamente `NUMBER` do Oracle usando `Number` e `intValue()`.

## Observações finais

- O sistema foi pensado para rodar com Oracle, não com MySQL/PostgreSQL;
- o usuário do banco deve ser o mesmo usado em `ConexaoBanco.java`;
- se o projeto for executado várias vezes, pode haver duplicidade de dados, então é importante limpar o banco ou usar valores novos para testes;
- o menu é a forma mais segura de executar e validar as operações manualmente.

## Dica

Antes de rodar o código pela primeira vez, faça uma verificação rápida:

```sql
SELECT USER FROM DUAL;
SELECT * FROM EQUIPE_MANUTENCAO;
SELECT * FROM TRECHO_RODOVIA;
SELECT * FROM INTERVENCAO_OPERACIONAL;
```

Se todas as tabelas estiverem vazias, o projeto pode iniciar normalmente e você pode cadastrar os dados pelo menu.
